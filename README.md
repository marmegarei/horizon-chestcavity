# Chest Cavity for Horizon

A port of [Chest Cavity](https://github.com/Tigereye504/chestcavity) (with Chest Cavity Beyond and
Astro Adds content) to [Horizon](https://github.com/horizon-rust/horizon), Minecraft rewritten in Rust.
Every player and mob has organs in their chest. Open it with the Chest Opener, swap organs, and live
with the consequences.

Status: version 0.6.2, built against Horizon Nightly 2026-11-08 (`fdc87ae`). Not everything of the
original is there yet: see [docs/nao-implementado.md](docs/nao-implementado.md) (in Portuguese).

## What works

- **Chest Opener**: right click in the air opens your own chest, on a mob opens its own (each species
  has its organs). Opening hurts 4, unless the chest is easy to open (doors count as organs).
- **Organs**: 254 organs and 291 items, tooltips with what each is better and worse at, a creative tab
  with all of them, mobs drop their organs.
- **Body**: eating (digestion, nutrition), breathing (lungs, gills), defenses, kidneys, heart, light,
  water, End Crystals, blows that launch or poison, wings.
- **Abilities**: key **V** (utility) and **R** (attacks), or `/cc ability <name>`: iron repair, grazing,
  silk, pyromancy, ghastly, dragon bombs, forceful spit, creeper blast.
- Commands: `/cc`, `/cc list`, `/cc take <slot>`, `/cc put`, `/cc ability <name>`; for operators
  `/cc open` and `/cc reset`.

## Layout

| Path | What |
|---|---|
| `native/shared/` | the rules, with no game in them (tests run anywhere) |
| `native/engine/` | the Horizon hooks that tie the rules to the game |
| `assets/`, `data/` | content generated by `tools/import.py` |
| `tools/package.py` | builds the `.hnmod` (code) and `.hmod` (content) into `target/` |
| `legacy-wasm/` | the old WebAssembly version (Horizon removed WASM mods) |

## Build

Native mods are compiled by the Horizon launcher, on the exact Horizon revision they pin:

```bash
python tools/package.py
# copy target/chestcavity.hnmod to <instance>/horizon-native-mods/ and
# target/chestcavity.hmod to <instance>/horizon-mods/, then:
horizon-launcher native-build --instance <instance> --trust-native-code
```

The engine's tests need the Horizon source (the `horizon-client` crate); `native/shared` tests run
with plain `cargo test`. `tools/import.py` regenerates `assets/`, `data/` and `organs.rs` from the
three upstream mods placed in `vendor/` (not included).
